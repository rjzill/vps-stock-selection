## 低价现货的两种来源

“现货”和“现货”不是一回事。市场上最便宜的那批有货机器，往往来自两个方向。

**第一种：商家改价的促销套餐。** HostDare 最近撤回了批量取消促销套餐的做法，改为调整价格，用户可选按新价续费、取消订单或另买新套餐。涉及的促销套餐有 CSSD0、CAMD0、CSSD0-promo、CAMD0-promo、CSSD1-promo、CSSD2-promo、CSSD3-promo、CAMD1-promo、CAMD2-promo、CAMD3-promo，新价格和细则都还没公布。促销价买到手，续费时按什么价走，是这类套餐最大的不确定项。

**第二种：二手过户机。** 六六云在售的一台香港优化线路，1 核 / 1024MB / 15GB / 150Mbps / 820GB 月流量，¥44/月，续费价过户后沿用原价和优惠规则，流量重置与服务截止都是 2026-12-11 22:16（UTC+8），平台记录更新于 2026-11-12 08:27，已用流量 6.25GB，卖家说明只有一句“刚买的 纯属瞎折腾”。

价格确实低，风险写在平台自己的提示里：

> 此VPS将保留现有系统和数据，原卖家可能仍掌握SSH密钥、系统密码或其它远程访问方式。过户只改变六六云账号归属。

平台建议验收后重装系统或更换全部凭证，验收期间不要写入敏感数据。买过户机省下的钱，要用一次彻底的系统重装和凭证轮换来换，这笔时间成本得算进去。

## “有货”和“好用”之间隔着白名单

11 月 12 日最值得看的一条事故：VMISS 的上游 IPv4 提供商对整个 207.57.0.0/16 的 BGP 宣告意外消失，所有使用 207.57.x.x 的服务不可达。判断是上游路由问题，不是虚拟机本身故障，恢复时间未定。

处置方式是替换所有受影响服务的 IP（207.57.140.0/24 除外，该段此前已更换）。新 IP 全球传播最长约 24 小时，恢复后先走普通国际中转，官方明确说明这不等于原先提供的大陆优化连接，延迟、路径、性能都可能有显著差异。更关键的是：**新 IP 还没完成电信、联通、移动的白名单，电信尤其慢，优化线路恢复没有确认时间表。**

补偿是先赠送 31 天，官方注明这只是初步措施，后续视白名单进度追加；207.57.140.0/24 那批已拿到新优化 IP 的服务，补偿是先前公布的 3 天。

同类情况还有 Spartan Host 西雅图：2026-11-10 19:00（北京时间）起，AS4837 与通往电信的 AS9929 再次出现高延迟和丢包，西雅图其他网络及其他机房不受影响，发稿时仍在持续。上一波从 11 月 9 日开始，AS4837 的拥堵在 11 月 10 日 01:34 左右缓解，AS9929 还在改善。

这两件事说明的问题是：一台机器今天显示有货，不代表今天拿来就能跑出你预期的速度。IP 段的运营商白名单状态、上游路由是否稳定，和库存是两套独立的变量。下单前能做的：问清分配的是哪个 IP 段，用 Looking Glass 或测试 IP 自己 ping 一遍，确认走的是 CN2 GIA 而不是临时国际中转。

还有一条容易踩的：评测整理提到圣何塞机房分配的 IP 分 38 段和 185 段，38 段是原生 IP，可以直接解锁 Netflix、Disney+ 这类流媒体，185 段不保证。官方条款里也写明 Looking Glass 的测试 IP 不代表实际分配段，不接受以“不是原生 IP”为由退款。冲着流媒体解锁去的，付款前要把这条想清楚。

## 常见问题

**补货提醒怎么设最省事？**

三种方式任选：浏览器网页推送，授权后套餐一补货就弹通知；连 Telegram 机器人，补货时私信你；或者直接进 Telegram 补货频道，所有商家的补货都发在里面。只想盯一两个套餐，用前两种；想看看市场整体什么时候放货，进频道。

**监控站的库存数据多久更新一次？**

按商家各自的频率直接读官网，快的几十秒一次、慢的几分钟一次。所以页面上显示“有货”，到你点进商家页面可能已经有变化，尤其是 CN2 GIA、9929、CMIN2 这类热门线路。

**为什么聚合站的价格和官网不一样？**

两个原因：抓取有时间差；人民币价格是折算出来的，汇率和折算脚本各家不同，有的公布（比如 1 USD = 7.2 CNY），有的不公布。买之前以商家下单页面为准，聚合站的价格只用来看相对高低。

**能不能按小时计费、随时退款？**

有第三方站点这样描述某家商家的计费方式，但那属于站点自述，没有在商家官方渠道核验过，不能当成官方政策。AkkoCloud 这边，能确认的是月付、季付、年付三种周期，退款限制见上文。想降低试错成本，先用最小的月付档跑一周，比直接上年付稳妥。
